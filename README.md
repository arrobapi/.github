# 🚀 Academia arrobaPi | Code Laboratory 💻

¡Bienvenido al repositorio oficial de pruebas y desarrollo de **Academia arrobaPi**! Este espacio está diseñado como nuestro laboratorio tecnológico, donde experimentamos con código, preparamos recursos interactivos, desplegamos prácticas de programación y testeamos los entornos para nuestros cursos de informática.

---

## 🏫 ¿Quiénes somos?
Desde **2005** en Ourense, en **Academia arrobaPi** nos apasiona conectar la lógica, las matemáticas y la informática. Impartimos clases individuales y en grupos reducidos con un enfoque totalmente personalizado, adaptándonos al ritmo de cada alumno, tanto en nuestra sede física como en modalidad online.

🎨 **Nuestra filosofía:** La informática no se aprende memorizando, ¡se aprende picando código y rompiendo cosas en entornos controlados como este!

---

## 🛠️ Tecnologías y Formación en Informática
En este laboratorio realizamos pruebas y preparamos material didáctico enfocado en las siguientes áreas:

* **💻 Fundamentos e Informática Básica:** Introducción a entornos operativos y alfabetización digital.
* **🐍 Programación y Lógica:** Desde los primeros pasos en lenguajes versátiles como **Python**, lógica algorítmica, hasta desarrollo local.
* **🌐 Desarrollo y Diseño Web:** Maquetación moderna utilizando estándares como **HTML** y hojas de estilo avanzadas en **CSS**.
* **📊 Ofimática Profesional:** Dominio de hojas de cálculo (Excel avanzado), procesadores de texto y bases de datos.
* **🤖 Inteligencia Artificial y Hardware:** Integración y pruebas de flujos de trabajo orientados a la educación tecnológica.

---

## 🧪 Contenido de este Repositorio
Este perfil y sus ramas se utilizan activamente para:
* Crear plantillas de código limpio para que los alumnos inicien sus proyectos.
* Probar flujos de integración, sistemas de control de versiones con Git y despliegues web rápidos.
* Alojar pequeños retos de código ("sandboxes") y scripts de prueba para las clases de programación.
